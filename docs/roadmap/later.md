Ideas worth keeping, none of them committed to.

- **LLM-written breaks**: replace templates with a local model (Ollama) given the same inputs,
  with the template as the fallback when the model is slow or says something odd. Facts only
  from tags and neighbeats (deadair's rule: no source, no claim).
- **Dayparts**: a weekly grid of mode/theme/talk frequency ("calm mornings", "rediscover on
  Sunday"). Maps to neighbeats' "journey stages" idea.
- **Lyric moments**: use `/v1/path` `theme` or lyric endpoints for themed hours.
- **Icecast + more mounts**: Opus for mobile data, FLAC at home; only if `output.harbor` stops
  being enough.
- **Hourly archive** to MP3 for replay.
- **Scrobbling** to ListenBrainz (self-hosted or not).
- **Waypoint routes** A → W → B (neighbeats M3 optional task) for "go via X".
- **Weather / news skills** in announcements (subwave's skills idea), templates only.
- **Several listeners**: whose taste steers, and licensing if it ever leaves the household.
- **A tiny status page** (read-only, now playing + history) behind the same Traefik auth.
